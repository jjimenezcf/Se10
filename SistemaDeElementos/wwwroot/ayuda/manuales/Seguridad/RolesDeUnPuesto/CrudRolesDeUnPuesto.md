# Roles de un puesto

Relación de los **roles asignados a un puesto de trabajo**. Se abre desde el puesto y está filtrada por él (filtro **Puesto**).

## ¿Cómo hago...?

### ...para añadir un rol al puesto?

**Crear** eligiendo el rol (p. ej. un `AFB: ...` para las opciones de menú y uno de datos para gestionar). **Borrar** lo quita.

### ...para buscar?

Filtro **Rol**.
